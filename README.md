# cleanflux

Clean structured JSON flux payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/cleanflux/

## Install / run

```bash
git clone https://github.com/theworker02/cleanflux.git
cd cleanflux
node src/cli.js
node --test
```
